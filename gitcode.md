# GitStudy1

# Git 学習メモ(更新中)

-CUIコード:
cd ~                                            :ホームディレクトリに移動

mkdir                                           :フォルダー新規作成

ls                                              :カレントディレクトリの中身を確認
ls -a                                           :隠しファイル含めて全員表示
ls -Documents                                   :"Documents"の内部の内容を表示

-git
git --vesion                                    :GitHubのバージョン表示

-======================================[設定]===============================================
git config                                      :GitHubのを設定する
git conifg --list                               :設定の一覧を確認する
git conifg --global user.name xxx               :Gitのglobalオプションでユーザー名指定
git conifg --global user.email xxx              :Gitのglobalオプションでメールアドレス指定
git conifg --global user.name                   :Gitのユーザー名設定を確認する
※global:アカウントごとの設定

git config --global core.editor                 :core.editorの設定を表示
git config --global core.editor "code --wait"   :VSCodeを作動しているとき、Gitの処理を一時停止
git config --global init.defaultBranch main     :最初のブランチを設定(名前:main)


-====================================[初期化]=============================================
git init                                        :初期化


-=======================================[確認]============================================
git status                                      :ローカルと登録情報の差分を取る
git branch                                      :現在のブランチの名前を確認

git diff                                        :差分表示
git diff -cached                                 :追加された状態でさらに変更した分を表示
git diff xxx(branch_name)                       :ブランチの間の変更を表示

※:多すぎて表示できないとき:[Enter]押すと1行下の変更を表示[Space]押すと全行表示
※実施後[q]押して戻る

git remote -v                                   :リポジトリの設定を確認する

-========================================[情報更新]========================================
git add .                                       :カレントディレクトリ配下のすべての変更を追加
git add xxx.(txt...)                            :配下の指定ファイルの変更を追加
git add xxx(フォルダー名)                        :配下のサブフォルダー内の変更を追加

※git add フォルダー名/ファイル名.(綴り)にすると指定サブフォルダー内指定ファイルで追加

-=======================================[取り消し]=========================================
git restore                                     :追加状態からコミットされている情報を取り戻す
git restore --staged filename                   :ステージされた変更を戻す

-=[reset]----------------------------------
git reset --hard (commit_hash)                  :コミット後の内容を強制巻き戻し
git reset --hard HEAD~(1,2)..                   :最新のコミットから(1,2..)個前の状態に戻す
※resetはも戻されたハッシュ以降の変更全部巻き戻す　
↑大切:共通環境に影響するかもしれないので一報してから作業!!!!
-=---------------------------------------

-=[revert]--------------------------------------
git revert --hard (commit_hash)                 :ブランチの変更をハッシュの状態に巻き戻す
git revert HEAD                                 :ブランチを1個前の状態に巻き戻す

※revertは失敗したコミット履歴そのまま残す(ハッシュバージョンのコピーを作る感じ)
---開発後の内容を間違ってコミットしたときの対策方法

↑大切:コンフリクト回避のため、複数前の状態に戻したいときも
"git revert HEAD"を複数回実行して戻す
-=------------------------------------------------------

-====================================[コミット]=============================================
git commit                                      :コミット
※git bashによって実行されるときはVSCodeでコミットメッセージを書く
(1行目:タイトル　2行目:空白　3行目:コミット内容)
git commit -m  "xxxx"                           :コミットメッセージ記載(1行のみ)

-====================================[ブランチ]============================================
git checkout                                    :ブランチをチェックアウト
git clone                                       :ブランチをクローンする
git pull                                        :チェックアウトした内容を同期する
git branch (new_branch_name)                    :ブランチを新規作成する
git switch                                      :ブランチ切り替え
git log                                         :ログ(コミット履歴)確認
git log -p                                      :コミット前後の差分確認
git push origin (branch_bame)                   :オリジナルブランチとしてGitHubにプッシュする

code xxx(path)                                  :このパスは以下のファイルをVSCodeで開く
code .                                          :カレントディレクトリ配下の内容をVSCodeで開く

-=====================================[削除]==============================================
git rm xxx(filename)                            :登録上のファイル削除
git rm -r subDirectory                          :subフォルダーの削除

-=====================================[無視]==============================================
".gitignore"というファイル作って、その中に無視されたいファイルのファイル名を格納
↑ファイルの拡張子は(".")に変更する
※git add やgit commitですでに管理されているファイルに使えません

-==================================[SSHキー]================================================
ssh-keygen -t ed25519 -C "xxx(email)"
↑終わったら保存先のファイル指定あります。「ed25519」はファイル名です

完了後パスワード2回打つ
最後SSHキーもらえます

clip < xxx(filename).pub                        :クリップボードに保存
※カレントディレクトリ直下じゃないときパスで指定

ssh -T git@github.com                           :SSH設定確認用コマンド

-====================================[ファイル新規作成]====================================
echo "# xxx(repositoryname)" >> xxx(filename)
